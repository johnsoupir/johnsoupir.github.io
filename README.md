# johnsoupir.github.io


This repository contains the source code for my personal website, built with Jekyll and hosted on GitHub Pages. The site contains project pages, an about/resume page, a contact form (using Formspree), and a tools page, among others.

## Repository Structure

- **about.md** – About me and resume page.
- **contact.md** – Contact page with a Formspree form.
- **index.html** – Home page featuring highlighted projects.
- **projects.html** – Overview of projects with reusable project cards.
- **tools.md** – A page listing useful tools and resources.
- **Projects/** – Contains directories for individual projects (each with its own subdirectories such as Images, Downloads, Video, etc.).
- **assets/** – Contains static assets (e.g., JavaScript).
- **_layouts/** – Jekyll layout files.
- **_includes/** – Jekyll include files (e.g., sidebar, project-card, figure).
- **styles.css** – Main CSS file.
- **_config.yml** – Jekyll configuration file.
