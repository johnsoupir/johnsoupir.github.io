## Overview

This project is a fully self-contained ASCII Rickroll written in both BASH and C. It can be used as a harmless pentesting payload, a fun Easter egg, or simply a demonstration of BASH scripting / C programming.

The fun part is that my rickroll requires no internet access and is fully self contained. You can even embed the C version inside your own project. A python version is in the works as well.
